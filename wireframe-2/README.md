# Smart Study Scheduler - Low Fidelity Wireframes

This folder contains low-fidelity HTML wireframes for each screen of the Smart Study Scheduler app. These wireframes are designed as simple sketches with dashed lines, basic shapes, and minimal styling to represent the layout and structure of each screen.

## 🎨 Low-Fidelity Design Features

### Visual Design Elements
- **Dashed borders** for all UI elements to simulate sketch-like appearance
- **Simple shapes** and basic geometric forms
- **Minimal colors** - primarily black, white, and gray
- **Basic typography** - Arial font with simple weight variations
- **No gradients or shadows** - flat, simple design
- **Placeholder content** - simple text and basic icons
- **Skeleton layout** - shows structure without detailed content

### Design Principles
- **Sketch-like appearance** with dashed lines and simple shapes
- **Focus on layout** rather than visual polish
- **Quick to create and modify** for rapid iteration
- **Clear hierarchy** through size and spacing
- **Minimal distractions** - focus on functionality and flow

## 🎯 Low-Fidelity Design System

### Borders and Lines
- **Dashed borders** (3px dashed) for all containers and cards
- **Thinner dashed borders** (2px dashed) for smaller elements
- **Solid borders** only for essential structural elements

### Colors
- **Primary**: #333 (dark gray) for main text and borders
- **Secondary**: #666 (medium gray) for secondary text
- **Background**: #fff (white) for content areas
- **Light gray**: #f0f0f0 for inactive elements
- **Accent**: #ff0000 (red) for logout/destructive actions

### Typography
- **Font**: Arial, sans-serif
- **Headings**: Bold, various sizes (18px-28px)
- **Body text**: Regular weight, 14px-16px
- **Labels**: Bold, 12px-14px
- **Captions**: Regular weight, 10px-12px

### Spacing
- **Consistent padding**: 15px-25px for cards and containers
- **Input fields**: 15px padding with dashed borders
- **Buttons**: 15px padding with dashed borders
- **Margins**: 10px-20px between elements

## 🔧 Customization Options

### Borders
- **Change border style**: Modify `border` properties from `dashed` to `solid` or `dotted`
- **Adjust border width**: Change `border-width` values
- **Update border color**: Modify `border-color` values

### Colors
- **Primary color**: Update `#333` to your preferred dark color
- **Secondary color**: Update `#666` to your preferred medium gray
- **Background**: Change `#fff` to your preferred background color

### Typography
- **Font family**: Replace `Arial` with your preferred font
- **Font sizes**: Adjust `font-size` values
- **Font weights**: Modify `font-weight` properties

### Layout
- **Spacing**: Update `padding` and `margin` values
- **Border radius**: Modify `border-radius` properties
- **Grid gaps**: Adjust `gap` values in grid layouts

## 📱 Screen Specifications
