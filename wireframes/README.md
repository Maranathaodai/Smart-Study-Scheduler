# Smart Study Scheduler - Low Fidelity Wireframes

This folder contains individual HTML wireframes for each screen of the Smart Study Scheduler app. These are low-fidelity wireframes designed for easy import into Figma for high-fidelity design work.

## 📱 Wireframe Files

### Authentication Screens
- `01-splash-screen.html` - App loading screen with logo
- `02-onboarding-screen.html` - Welcome and setup introduction
- `03-login-screen.html` - User login with email/name and password
- `04-signup-screen.html` - Account creation form

### Main App Screens (with Tab Navigation)
- `05-dashboard-screen.html` - Home screen with daily motivation and quick actions
- `06-courses-screen.html` - Course management with empty state for new users
- `07-calendar-screen.html` - Monthly calendar view with study sessions
- `08-progress-screen.html` - Progress tracking and statistics
- `09-profile-screen.html` - User profile and settings

### Secondary Screens
- `10-add-course-screen.html` - Course creation form with color selection
- `11-daily-study-screen.html` - Study session interface with chunks and tips
- `12-edit-profile-screen.html` - Profile editing form
- `13-goals-screen.html` - Daily and weekly goal tracking
- `14-notifications-screen.html` - Study reminders and achievements

## 🎨 Design Features

### Low-Fidelity Styling
- **Simple grayscale color scheme** (black, white, grays)
- **Basic shapes and rectangles** for UI elements
- **Minimal typography** with clear hierarchy
- **No complex graphics or images** - just placeholders
- **Clean, functional layouts** focused on structure

### Key Elements
- **iPhone-style frames** with status bar and rounded corners
- **Tab navigation** at the bottom for main screens
- **Card-based layouts** for organized content
- **Empty states** for new users (no dummy data)
- **Progress indicators** and statistics displays
- **Form inputs** and interactive elements
- **Menu items** with icons and navigation arrows

## 📋 How to Use with Figma

1. **Open each HTML file** in your web browser
2. **Take screenshots** of each wireframe at full size
3. **Import to Figma** using the "Import" feature
4. **Use as reference** for your high-fidelity designs
5. **Trace over** the wireframes to create your final designs
6. **Replace placeholders** with actual content and styling

## 🔧 Customization

Each wireframe is self-contained and can be easily modified:
- **Colors**: Change the grayscale values to match your brand
- **Typography**: Adjust font sizes and weights
- **Spacing**: Modify padding and margins
- **Layout**: Rearrange elements as needed
- **Content**: Update text and placeholder content

## 📱 Screen Specifications

- **Frame Size**: 300px × 600px (iPhone-like proportions)
- **Status Bar**: 30px height with time and battery indicators
- **Header**: 60px height for screen titles
- **Tab Bar**: 60px height for bottom navigation
- **Content Area**: Flexible height with scrollable content
- **Border Radius**: 25px for screen corners, 8px for cards

## 🎯 Key Design Principles

1. **User-First**: All screens show empty states for new users
2. **Clean & Simple**: Minimal visual clutter, focus on functionality
3. **Consistent**: Uniform spacing, typography, and component styles
4. **Accessible**: Clear contrast and readable text sizes
5. **Mobile-Optimized**: Touch-friendly button sizes and spacing
